# Brotinho 🌱💸

Controle financeiro pessoal em React + Vite, com autenticação e dados no Supabase.

## Variáveis de ambiente
Configure na Vercel:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`

## Banco de dados
Execute `supabase/schema.sql` no SQL Editor do projeto Brotinho.

## Segurança
O app usa Supabase Auth e RLS para separar os dados por usuário.
